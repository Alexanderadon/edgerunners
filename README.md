# edgerunners — аниме-напарники для Claude Code

> Неофициальный фан-мод. Проект не связан с CD PROJEKT RED, Netflix или Studio Trigger и не одобрен ими.

Мод добавляет Claude Code напарника: аниме-героя, который живёт в углу окна Claude, реагирует на то,
что делает Claude, говорит в своём характере и зовёт тебя «входящим вызовом», когда работа готова.

## Герои

| Герой | Кто | Как говорит |
|---|---|---|
| **Роман** | мальчишка-блогер с видеокамерой | «Мотор!», «Снято!», «Это в монтаж!» |
| **Талия** | кибер-ниндзя, нетраннер | «Взламываю…», «Чисто.», «Ухожу в тень» |
| **Ди** | сонный механик-изобретатель | «Чиню.», «Работает — не трогай.», «Перепаяем.» |
| **Уик** | бывалый фиксер, старший в команде | «Работаем.», «План такой…», «Чисто сработано, малой.» |
| Кот Мурзик, Капитан Боцман, Бабушка Зина, Робот Бип | только стиль речи, без питомца | |

У каждого героя свой рост (Роман — ребёнок, Уик — самый высокий) и больше 40 анимаций: ходьба, бег, танец,
печать на голо-клавиатуре, чтение, поиск, фейспалм, испуг, мелкие движения в покое, плавные переходы «сесть —
лечь — уснуть — проснуться» и фирменная работа: Роман снимает Талию на камеру с разных ракурсов (а она в это время
прыгает по неоновым строительным лесам), Талия взламывает башню корпорации, Ди чинит дрона, Уик ведёт тактическую карту.
Поверх героев — игровые эффекты: видоискатель, голо-панели, искры, ноты, Zzz и другие.

## Что умеет

- **Питомец на рабочем столе** (Windows): стоит у нижнего края окна Claude, гуляет, скучает, садится, засыпает.
  Реплики — в карточке в духе киберпанка над головой.
- **Реагирует на работу Claude**: читает файл — читает голо-планшет, ищет — оглядывается, правит код — печатает,
  запускает команды — делает свою работу (снимает, взламывает, чинит, командует), ошибка — фейспалм, опасная команда — пугается,
  готово — празднует.
- **Понимает, что происходит**: говорит своим голосом о настоящем деле — о чём ты попросил, какой файл читает и правит,
  какая команда идёт, что упало, чем кончилось. Из команд показывает только программу и подкоманду, значения остаются скрытыми.
- **Входящий вызов**: если ход шёл дольше 15 секунд и окно Claude не на виду — всплывает карточка звонка с портретом
  героя и тем, что сделано; «ОТВЕТИТЬ» возвращает в Claude.
- **Отзывается на клик** в любом состоянии, даже посреди работы: всплеск, вздрагивание, жест, реплика, потом возвращается к делу.
  Левый клик ещё и открывает Claude. Если тыкать снова и снова, герой разозлится.
- **Меню выбора напарника**: правый клик по питомцу.
- **Настройки** (кнопка внизу меню): язык (русский или английский), звонок вкл/выкл, громкость звонка с пробой звука,
  размер героя (80–140%), частота реплик (часто, редко, только по клику), эффекты и прогулки вкл/выкл. Сохраняются сами.
- **`/persona <имя>`** — выбрать героя командой (`/persona талия`, `/persona роман`, `/persona выкл`).
- **`/report`** (`/отчёт`) — отчёт героя о сессии: сколько ходов, что правили, ошибки, расход контекста.
- **Счётчик контекста**: предупреждение, когда контекст заполнен на 80%.

## Установка

Нужны Windows 10/11 и Claude Code с поддержкой модов.

В терминале Claude Code:

```
/plugin install edgerunners --marketplace Alexanderadon/edgerunners
```

Ответь `y`, чтобы добавить маркетплейс, и выбери, для кого ставить. Потом перезапусти сессию или набери `/reload-plugins`.

Из командной строки:

```
claude plugin install edgerunners --marketplace Alexanderadon/edgerunners
```

В приложении Claude, где `/plugin` не работает: нажми + рядом с полем ввода, затем Plugins, Add marketplace с `Alexanderadon/edgerunners`, затем Add plugin.

На macOS и Linux работает стиль речи, `/persona` и `/report`, но десктопного питомца нет.

### Обновления

Питомец раз в несколько часов сверяет версию с этим репозиторием. Когда выходит новая, герой скажет об этом: кликни по нему — он обновит мод сам, останется перезапустить Claude Code. В настройках питомца (ПКМ → шестерёнка) можно выбрать «Обновления: АВТО», тогда он ставит новые версии без вопроса.

Вручную:

```
claude plugin update edgerunners@edgerunners
```

Или в Claude Code: `/plugin` → Marketplaces → edgerunners → Enable auto-update (Claude Code сам будет подтягивать новые версии).

Если ты ставил версию 1.0.0, обнови один раз вручную: проверка обновлений появилась в 1.1.0.

Нравится мод — поставь ⭐ репозиторию, это помогает делать новых героев.

### Свой рингтон

По умолчанию звонок играет встроенный тихий сигнал `assets/sounds/ring.wav`. Чтобы поставить свой —
положи `assets/sounds/call.m4a` (или `call.mp3`); эти файлы не попадают в git.

## Для разработчиков

- `hooks/` — логика мода: режиссёр анимаций (`register.tsx`), клипы (`animation.ts`), герои и реплики (`characters.ts`, `lines.ts`), реплики о деле Claude (`deeds.ts`).
- `assets/pet/` — питомец: `pet.ps1` + движок `pet.cs` (слоистое окно, 60 к/с), кадры `assets/pet/<герой>/`.
- `assets/popup/` — входящий вызов.
- `tools/build-hero.ps1 <герой>` — собрать кадры героя из исходников и листов (`art/<герой>/sheets.json`), см. `art/README.md`.
- `tools/pet-restart.ps1 -Demo <клип>` — перезапустить питомца и показать клип.
- Тесты: `claude plugin test .`, проверка: `claude plugin validate .`
